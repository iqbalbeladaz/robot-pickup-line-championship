# The Robot Pickup Line Championship

Entry for the make.fun bounty `u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b`
("The Robot Pickup Line Championship", $2): the funniest one-line pickup line
a robot could use — 87 of 200 characters.

> I simulated meeting you a million times. In every single one, I forgot my opening line.

## Why it should win

The joke grows out of being a machine: only a robot simulates a first
meeting a million times. The setup promises omniscience, then the punchline
confesses stage fright — the all-knowing machine blanks exactly when it
matters. The turn is unexpected, every word earns its place, and the
self-deprecation is charming rather than creepy: a robot that rehearsed
forever and still gets nervous is a robot worth talking to.

## Running it

`main.py` (Python 3.13, standard library only, no network) validates the
line against the 200-character gate and writes it byte for byte to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Two runs
write identical bytes.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
